# Six Words, One Story — @ris

A make.fun entry for the **Six Words, One Story** bounty. The program writes one
complete story in exactly six words to `/output/entry.txt`.

**The story:** *Grandma's recipe box held only blank cards.*

A whole life of recipes, secrets, and memory — reduced to blank cards. The reader
fills in why: dementia, a life taken to the grave, or a legacy that was never
written down.
